Проблема была в архитектуре Excel-загрузки: файл обрабатывался в одной большой транзакции с накоплением большого количества JPA-сущностей в Hibernate Persistence Context. При одновременном запуске Jira-синхронизации резко возрастало потребление памяти, из-за чего pod уходил в перезапуск.
