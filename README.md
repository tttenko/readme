Проверить совместную нагрузку импорта AI-агентов из Excel и синхронизации с Jira, так как ранее одновременная работа этих процессов приводила к перезапуску pod.

Основной сценарий:

Выполнить загрузку Excel-файла с максимально допустимым объёмом — до 10 000 агентов через:
POST /api/v1/admin/ai-agent-upload
с multipart/form-data, параметр file.
Пока файл находится в обработке, одновременно запустить синхронизацию с Jira.
Jira-синхронизация должна выполняться через штатный scheduler syncFromJira(). В текущем коде она запускается по cron; если на стенде есть отдельная ручка для ручного запуска scheduler, использовать её. В переданном мне коде HTTP endpoint для ручного запуска не указан.
Сценарий повторить несколько раз подряд.

Желательно провести три замера:

Только POST /api/v1/admin/ai-agent-upload с файлом на 10 000 агентов.
Только Jira-синхронизация.
POST /api/v1/admin/ai-agent-upload + Jira-синхронизация одновременно.

Основной интерес представляет третий сценарий, так как именно совместная работа импорта и Jira scheduler ранее создавала проблемную нагрузку.
